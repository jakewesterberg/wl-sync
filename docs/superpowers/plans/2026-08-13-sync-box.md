# wl-sync — Sync Box: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone package producing the master timebase for every recording rig — barcode generation, event-strobe capture, and the on-disk log that everything downstream aligns to.

**Architecture:** The codec and log format are **pure Python with no hardware dependency**, so they run in CI on any machine; `pigpio` is reached only through a thin adapter with an in-memory fake, and lives behind an optional extra. `wl-preproc` installs this package to decode barcodes and read logs — the dependency runs one way only, because the sync box owns everything it produces.

**Tech Stack:** Python 3.11, Pydantic v2, pytest, pigpio (Raspberry Pi 4 only, optional extra)

**Spec:** [`../../../../wl-preproc/docs/superpowers/specs/2026-08-12-wl-preproc-design.md`](../../../../wl-preproc/docs/superpowers/specs/2026-08-12-wl-preproc-design.md) §4.1, §4.3, §4.5

## Global Constraints

- **Python 3.11.** Matches the wl-preproc environment, which is pinned by the Kilosort4/PyTorch requirement for Pascal (`sm_61`, CUDA 12.x).
- **Raspberry Pi 4, not Pi 5.** `pigpio` drives BCM2711-and-earlier DMA/GPIO peripherals directly and does not support the Pi 5's RP1 southbridge.
- **DMA, never interrupt handlers.** All timing goes through `pigpio`'s DMA engine — waveform generation for output, DMA sampling for capture — so the Linux scheduler is out of the timing path.
- **`pigpio` is an optional extra.** The core package must import and test with no Pi libraries present.
- **Barcode:** 32-bit monotonic counter, 5 ms bit slot, 10 ms wrapper pulse, 200 ms frame, 1 Hz interval.
- **The counter is never reset**, across sessions or reboots, so every barcode the lab emits is globally unique.
- **Pi GPIO is 3.3 V and not 5 V tolerant.** Level shifting is a hardware requirement (spec §4.3); this package assumes it exists and cannot detect its absence.

```python
# wl_sync/session.py
"""Session identity, generated by the sync box at session start.

The sync box owns this format because it is the thing that mints it. Everything
downstream — the rig directory layout, the ELN, wl-preproc — consumes it.
"""

from __future__ import annotations

import datetime
import re
from dataclasses import dataclass

_SESSION_ID_RE = re.compile(r"^(\d{4})-(\d{2})-(\d{2})_(\d{2})$")


@dataclass(frozen=True, slots=True)
class SessionId:
    date: datetime.date
    index: int

    @classmethod
    def parse(cls, text: str) -> SessionId:
        match = _SESSION_ID_RE.match(text)
        if match is None:
            raise ValueError(f"malformed session id: {text!r}, expected YYYY-MM-DD_NN")
        year, month, day, index = (int(group) for group in match.groups())
        return cls(datetime.date(year, month, day), index)

    def __str__(self) -> str:
        return f"{self.date.isoformat()}_{self.index:02d}"
```

`datetime.date` rejects month 13, so `"2027-13-01_01"` raises `ValueError` from the constructor rather than the regex.

```python
    for level, duration in pulses:
```

```python
# wl_sync/barcode.py
"""Barcode codec. Pure — no hardware dependency, so it runs in CI.

Frame layout, 200 ms total:

    LEAD   HIGH 10 ms
    GAP1   LOW  10 ms
    DATA   32 x 5 ms, MSB first, HIGH = 1
    GAP2   LOW  10 ms
    TRAIL  HIGH 10 ms

Emitted once per second, so 800 ms of idle LOW separates frames. A frame starts
at "a rising edge after at least IDLE_MIN_US of LOW", which is what distinguishes
the lead pulse from a run of set bits. The longest LOW run *inside* a frame is
180 ms — an all-zero payload plus both gaps — comfortably under the threshold.

Consequence of requiring the preceding idle: a frame decodes only if the window
also contains the end of the previous frame. That yields one barcode guaranteed
in any 2.0 s window and two in any 3.0 s window. One is sufficient, because the
timebase inherits clock rate from a session-wide fit and needs only an offset.

A 32-bit counter at 1 Hz stays unique for ~136 years, so barcode values can never
be confused between sessions.
"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass

BIT_SLOT_US = 5_000
WRAPPER_US = 10_000
N_BITS = 32
FRAME_US = 4 * WRAPPER_US + N_BITS * BIT_SLOT_US  # 200_000
INTERVAL_US = 1_000_000
IDLE_MIN_US = 400_000

_MAX_VALUE = (1 << N_BITS) - 1
_QUARTER = WRAPPER_US // 4


@dataclass(frozen=True, slots=True)
class Barcode:
    value: int
    start_us: int  # tick of the LEAD rising edge


def encode(value: int) -> list[tuple[int, int]]:
    """Return (level, duration_us) pulses for one frame."""
    if not 0 <= value <= _MAX_VALUE:
        raise ValueError(f"barcode value out of 32-bit range: {value}")
    pulses: list[tuple[int, int]] = [(1, WRAPPER_US), (0, WRAPPER_US)]
    for position in range(N_BITS - 1, -1, -1):
        pulses.append(((value >> position) & 1, BIT_SLOT_US))
    pulses.append((0, WRAPPER_US))
    pulses.append((1, WRAPPER_US))
    return pulses


def edges_from_samples(
    trace: Sequence[int], fs_hz: float, t0_us: int = 0
) -> list[tuple[int, int]]:
    """Convert a sampled digital trace into (tick_us, level) transitions."""
    edges: list[tuple[int, int]] = []
    previous: int | None = None
    for index, sample in enumerate(trace):
        level = 1 if sample else 0
        if level != previous:
            edges.append((t0_us + round(index / fs_hz * 1_000_000), level))
            previous = level
    return edges


def _level_at(edges: Sequence[tuple[int, int]], tick_us: int) -> int:
    level = 0
    for edge_tick, edge_level in edges:
        if edge_tick > tick_us:
            break
        level = edge_level
    return level


def decode_edges(edges: Sequence[tuple[int, int]]) -> list[Barcode]:
    """Decode complete frames. Partial and unverifiable frames are discarded."""
    ordered = sorted(edges)
    if not ordered:
        return []

    barcodes: list[Barcode] = []
    last_falling: int | None = None

    for tick, level in ordered:
        if level == 0:
            last_falling = tick
            continue
        if last_falling is None or tick - last_falling < IDLE_MIN_US:
            continue

        start = tick
        if ordered[-1][0] < start + FRAME_US:
            continue  # frame extends past the data we hold

        # LEAD must be exactly one wrapper wide, and GAP1 must follow it.
        if _level_at(ordered, start + _QUARTER) != 1:
            continue
        if _level_at(ordered, start + 3 * _QUARTER) != 1:
            continue
        if _level_at(ordered, start + WRAPPER_US + _QUARTER) != 0:
            continue
        if _level_at(ordered, start + WRAPPER_US + 3 * _QUARTER) != 0:
            continue

        data_start = start + 2 * WRAPPER_US
        value = 0
        for bit in range(N_BITS):
            centre = data_start + bit * BIT_SLOT_US + BIT_SLOT_US // 2
            value = (value << 1) | _level_at(ordered, centre)

        gap2 = data_start + N_BITS * BIT_SLOT_US
        if _level_at(ordered, gap2 + WRAPPER_US // 2) != 0:
            continue
        if _level_at(ordered, gap2 + WRAPPER_US + WRAPPER_US // 2) != 1:
            continue

        barcodes.append(Barcode(value=value, start_us=start))
        last_falling = None
    return barcodes
```

```python
# wl_sync/log.py
"""Sync box on-disk log.

One JSON header line, then one CSV line per edge — readable with standard tools
on a rig PC at 8am, which is when it matters.

pigpio reports a 32-bit microsecond tick that wraps roughly every 72 minutes, so
raw ticks must be unwrapped before use. A session outlives several wraps.
"""

from __future__ import annotations

import datetime
import json
from collections.abc import Iterable, Sequence
from dataclasses import dataclass
from pathlib import Path

from pydantic import BaseModel, ConfigDict, field_validator

from wl_sync.session import SessionId

TICK_WRAP_US = 1 << 32
SCHEMA_VERSION = 1


class SyncBoxLogHeader(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    schema_version: int
    session_id: str
    rig: str
    boot_id: str
    written_at: datetime.datetime
    gpio_map: dict[str, int]

    @field_validator("session_id")
    @classmethod
    def _session_id_well_formed(cls, value: str) -> str:
        SessionId.parse(value)
        return value

    @field_validator("written_at")
    @classmethod
    def _must_be_aware(cls, value: datetime.datetime) -> datetime.datetime:
        if value.tzinfo is None or value.utcoffset() is None:
            raise ValueError("written_at must be timezone-aware")
        return value


@dataclass(frozen=True, slots=True)
class Edge:
    tick_us: int
    gpio: int
    level: int


def unwrap_ticks(raw: Sequence[int]) -> list[int]:
    """Undo pigpio's 32-bit tick wraparound, assuming edges arrive in order."""
    unwrapped: list[int] = []
    offset = 0
    previous: int | None = None
    for tick in raw:
        if previous is not None and tick < previous:
            offset += TICK_WRAP_US
        unwrapped.append(tick + offset)
        previous = tick
    return unwrapped


def write_log(path: Path, header: SyncBoxLogHeader, edges: Iterable[Edge]) -> None:
    with path.open("w", encoding="utf-8") as handle:
        handle.write(json.dumps(header.model_dump(mode="json")) + "\n")
        for edge in edges:
            handle.write(f"{edge.tick_us},{edge.gpio},{edge.level}\n")


def read_log(path: Path) -> tuple[SyncBoxLogHeader, list[Edge]]:
    with path.open("r", encoding="utf-8") as handle:
        header = SyncBoxLogHeader.model_validate(json.loads(handle.readline()))
        edges: list[Edge] = []
        for line in handle:
            stripped = line.strip()
            if not stripped:
                continue
            tick, gpio, level = (int(part) for part in stripped.split(","))
            edges.append(Edge(tick_us=tick, gpio=gpio, level=level))
    return header, edges
```

```python
# wl_sync/gpio.py
"""GPIO backend protocol and an in-memory fake.

pigpio is reached only through this seam, so the firmware logic runs in CI on a
laptop with no Pi libraries installed. The real backend is the pigpio module
itself, which already satisfies this protocol without adaptation.
"""

from __future__ import annotations

from collections.abc import Callable
from typing import Protocol


class GpioBackend(Protocol):
    def wave_clear(self) -> None: ...
    def wave_add_generic(self, pulses: list[tuple[int, int, int]]) -> int: ...
    def wave_create(self) -> int: ...
    def wave_send_once(self, wave_id: int) -> int: ...
    def callback(self, gpio: int, edge_cb: Callable[[int, int, int], None]) -> object: ...
    def get_current_tick(self) -> int: ...


class FakePigpio:
    """Records waves and dispatches injected edges. Test double only."""

    def __init__(self) -> None:
        self.sent_waves: list[list[tuple[int, int, int]]] = []
        self._pending: list[tuple[int, int, int]] = []
        self._waves: dict[int, list[tuple[int, int, int]]] = {}
        self._callbacks: dict[int, list[Callable[[int, int, int], None]]] = {}
        self._next_wave_id = 0
        self._tick = 0

    def wave_clear(self) -> None:
        self._pending = []

    def wave_add_generic(self, pulses: list[tuple[int, int, int]]) -> int:
        self._pending.extend(pulses)
        return len(self._pending)

    def wave_create(self) -> int:
        wave_id = self._next_wave_id
        self._next_wave_id += 1
        self._waves[wave_id] = list(self._pending)
        self._pending = []
        return wave_id

    def wave_send_once(self, wave_id: int) -> int:
        self.sent_waves.append(self._waves[wave_id])
        return wave_id

    def callback(self, gpio: int, edge_cb: Callable[[int, int, int], None]) -> object:
        self._callbacks.setdefault(gpio, []).append(edge_cb)
        return object()

    def get_current_tick(self) -> int:
        return self._tick

    def inject_edge(self, gpio: int, level: int, tick: int) -> None:
        self._tick = tick
        for callback in self._callbacks.get(gpio, []):
            callback(gpio, level, tick)
```

```python
# wl_sync/service.py
"""Barcode generation and edge capture.

All timing goes through pigpio's DMA engine — waveforms for output, DMA sampling
for capture — so the Linux scheduler is out of the timing path entirely. Nothing
here uses an interrupt handler or a Python timer.
"""

from __future__ import annotations

from wl_sync.barcode import encode
from wl_sync.gpio import GpioBackend
from wl_sync.log import TICK_WRAP_US, Edge


class BarcodeGenerator:
    """Emits one barcode frame per call, incrementing a monotonic counter.

    The counter is never reset — across sessions or reboots — so every barcode the
    lab ever emits is globally unique and cross-session mis-alignment is
    structurally impossible rather than merely unlikely.
    """

    def __init__(self, backend: GpioBackend, gpio: int, start_value: int) -> None:
        self._backend = backend
        self._gpio = gpio
        self.next_value = start_value

    def emit_frame(self) -> int:
        value = self.next_value
        mask = 1 << self._gpio
        pulses = [
            (mask if level else 0, 0 if level else mask, duration)
            for level, duration in encode(value)
        ]
        self._backend.wave_clear()
        self._backend.wave_add_generic(pulses)
        self._backend.wave_send_once(self._backend.wave_create())
        self.next_value = value + 1
        return value


class EdgeRecorder:
    """Captures transitions on registered GPIOs, unwrapping pigpio's 32-bit tick."""

    def __init__(self, backend: GpioBackend, gpios: list[int]) -> None:
        self._backend = backend
        self._gpios = list(gpios)
        self._edges: list[Edge] = []
        self._offset = 0
        self._previous_raw: int | None = None

    def start(self) -> None:
        for gpio in self._gpios:
            self._backend.callback(gpio, self._on_edge)

    def _on_edge(self, gpio: int, level: int, tick: int) -> None:
        if gpio not in self._gpios:
            return
        if self._previous_raw is not None and tick < self._previous_raw:
            self._offset += TICK_WRAP_US
        self._previous_raw = tick
        self._edges.append(Edge(tick_us=tick + self._offset, gpio=gpio, level=level))

    def edges(self) -> list[Edge]:
        return list(self._edges)
```
