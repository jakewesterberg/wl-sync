### Task 0.1: A cycle-accurate interpreter for PIO instruction words, which sees today's fault

**Files:**
- Create: `tests/piosim.py`
- Create: `tests/test_piosim.py`

**Interfaces:**
- Consumes: nothing.
- Produces, in `tests/piosim.py`, imported as `from tests.piosim import ...` (`pyproject.toml` sets `pythonpath = ["."]`):
  - `M32 = 0xFFFF_FFFF`;
  - `run(words: Sequence[int], *, entry: int, wrap_target: int, wrap: int, cycles: int, strobe: Callable[[int], bool] = lambda c: False, data: Callable[[int], int] = lambda c: 0, x: int = M32) -> Run`;
  - `@dataclass class Run`, with these fields:
    - `cycles: int`;
    - `x: int`;
    - `decrement_cycles: list[int]`, the cycle of every `jmp x--`;
    - `zero_at: list[int]`, the address of each `jmp x--` that found X == 0;
    - `pushes: list[tuple[int, int]]`, as (cycle, word);
    - `visited: set[int]`;
    - and the property `decrements -> int`;
  - `class LeftProgram(AssertionError)` with `.cycle: int` and `.address: int`;
  - `class Unmodelled(ValueError)`;
  - `high_during(intervals: Sequence[tuple[int, int]]) -> Callable[[int], bool]`: high on each `[rise, fall)`;
  - `strobe_train(seed: int, count: int, *, widths=(2, 300), lows=(2, 400), spacing=12, start=10) -> list[tuple[int, int]]`.

**What the interpreter models, and nothing more.** These are the semantics this repository already assumes (`pio/strobe_capture.pio:101-108`, `wl_sync/rp1/program.py:42-56`, both at c744189). The bench's P0 checks them on silicon.
- **Cycles.** One instruction per cycle, cycle 0 being the first. The delay/side-set field (bits 12:8) must be 0, or `Unmodelled` is raised. A delay would change the cycle count, and ignoring it would make every result here wrong.
- **JMP** (bits 15:13 = `000`). The target is bits 4:0. The condition is bits 7:5:
  - `000`, always: jumps;
  - `010`, `x--`: jumps iff X ≠ 0 *before* the decrement, and decrements X mod 2³² either way. When X was 0, the address goes to `zero_at`;
  - `110`, `pin`: jumps iff `strobe(cycle)`;
  - anything else: `Unmodelled`.
- **IN** (`010`): the source (bits 7:5) must be `000`, pins. The count is bits 4:0, where 0 means 32. ISR becomes `((ISR << n) | (data(cycle) & (2ⁿ−1))) & M32`, a left shift as `in_shiftdir` LEFT gives (`wlsync_pio.c:121-123`). There is no autopush.
- **PUSH** (`100`, bit 7 = 0): only `push noblock`, the word `0x8000`, is modelled. It appends `(cycle, ISR)` and clears ISR. The RX FIFO here is unbounded: the host's drain and its full flag are `test_rp1_backend.py`'s to test.
- **MOV** (`101`): only two words are modelled.
  - `0xA0C1`, `mov isr, x`: ISR = X.
  - `0xA02B`, `mov x, ~null`: X = `M32`. This is the seed (`program.py:75-78`).
  - Any other MOV is `Unmodelled`.
- **Any other opcode** (WAIT, OUT, PULL, IRQ, SET) is `Unmodelled`.
- **The next PC.** After an instruction that did not jump, the PC becomes `wrap_target` if it was `wrap`, and PC + 1 otherwise.
- **Leaving the program.** Before each cycle, a PC outside `range(len(words))` raises `LeftProgram(cycle, address)`.

`strobe_train`'s body, because the tests' numbers depend on it:

```python
rng = random.Random(seed)
rise, train = start, []
for _ in range(count):
    width = rng.randint(*widths)
    train.append((rise, rise + width))
    rise = max(rise + width + rng.randint(*lows), rise + spacing)
return train
```

**Interfaces:**
- Produces:
  - `clockmap.TickScale(rate_ppb: int = 0)`: a frozen dataclass whose `rate_ppb` is r − 1 in ppb, where r is the PIO counts per SI µs. Its method `tick(counts: int) -> int` computes `(2 * counts * 10**9 + d) // (2 * d)` with `d = 10**9 + rate_ppb`, which is round-half-up of `counts / r`.
  - `clockmap.IDENTITY = TickScale(0)`;
  - `Recorder(backend, sink=None, scale: TickScale = IDENTITY)`.
- **The rule:**
  - the Recorder unwraps raw P on `_BoxClock` exactly as today, then calls `scale.tick` on the unwrapped value, in `_on_word`, `_on_edge`, `record_barcode`, `now()` and `delivered_through()`;
